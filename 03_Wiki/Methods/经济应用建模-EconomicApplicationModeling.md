经济应用问题的解题思路：

4. **求解优化**：利用导数求极值

## 常用模型

### 边际与总量

由边际成本 $C'(Q)$ 求总成本 $C(Q)$（固定成本 $C_0$）：

$$
C(Q) = \int_0^Q C'(t) \, \mathrm{d}t + C_0.
$$

### 需求弹性反求需求函数

由需求价格弹性 $\eta = -\frac{p}{Q} \frac{\mathrm{d}Q}{\mathrm{d}p}$ 及初始条件，解微分方程得需求函数 $Q = Q(p)$.

### 利润最大化

$$
L(Q) = R(Q) - C(Q), \quad L'(Q) = 0 \Rightarrow R'(Q) = C'(Q).
$$

## 典型例题

**条件**：边际成本 $C'(x) = 4 + \frac{x}{4}$，固定成本 $C(0) = 1$ 万元，需求弹性 $\eta = \frac{p}{8-p}$，最大需求量 $8$。

**求解**：
1. $C(x) = \int_0^x (4 + \frac{t}{4}) \, \mathrm{d}t + 1 = 4x + \frac{x^2}{8} + 1$
2. 解 $\frac{\mathrm{d}x}{x} = \frac{\mathrm{d}p}{p-8}$ 得 $x = 8 - p$，$R(x) = 8x - x^2$
3. $L(x) = R(x) - C(x) = -\frac{9}{8}x^2 + 4x - 1$
4. $L'(x) = 0 \Rightarrow x = \frac{16}{9}$，$p = 8 - x = \frac{56}{9}$

## 注意事项

- 经济应用中需注意变量的实际含义和取值范围
- 弹性为正时需注意符号约定（通常 $\eta > 0$ 表示需求弹性）
- 积分时注意固定成本等初始条件
