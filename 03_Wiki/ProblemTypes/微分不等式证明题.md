# 微分不等式证明题

## 识别信号

- 待证不等式涉及函数值之间的大小关系
- 通常需要移项构造 $F(x)$
- 题目形式如"证明 $f(a) < f(b)$" 或 "$f(x) > g(x)$ 在某区间成立"

## 三种主要方法

### 1. 单调性法

- **适用场景**：不等式仅涉及一个函数
- **步骤**：
  1. 移项，构造 $F(x) = f(x) - g(x)$
  2. 求导 $F'(x)$
  3. 判断 $F'(x)$ 的符号
  4. 若 $F'(x) > 0$，则 $F(x)$ 单调递增

### 2. 中值定理法

- **适用场景**：不等式涉及两个函数值之差
- **步骤**：
  1. 用拉格朗日将函数差转化为导数
  2. $f(b) - f(a) = f'(\xi)(b-a)$
  3. 对 $f'(\xi)$ 进行放缩

### 3. 泰勒公式法

- **适用场景**：高阶导数出现或区间较大
- **步骤**：
  1. 选择合适的展开点
  2. 在展开点处泰勒展开
  3. 利用余项进行估计

## 方法选择信号

| 条件 | 推荐方法 |
|------|----------|
| 不等式仅涉及一个函数 | 优先单调性 |
| 不等式涉及两个函数值之差 | 优先拉格朗日 |
| 高阶导数出现或区间较大 | 优先泰勒 |
| 函数表达式简单可直接求导 | 优先单调性 |

## 避坑指南

- **绝对值函数不可导**：做题时需先处理绝对值，去掉绝对值符号化为分段函数
- **泰勒展开需注意展开点选择**：展开点通常选在区间内部或中点
- 放缩时注意方向：不能反向放缩
- 区间端点处需单独验证
