# 中值定理极限题

## 识别信号

- 题目中出现"存在 $\theta\in(0,1)$ 使得..." 或 "$\xi$"
- 最终要求某个含参数的极限
- 形式如 $\lim_{x\to x_0} \frac{f(x) - f(x_0)}{g(x)}$ 或类似含 $\theta$ 的表达式

## 步骤 SOP

1. **用中值定理建立等式**
   - 根据题目条件，选择拉格朗日或柯西中值定理
   - 建立 $f(b) - f(a) = f'(\xi)(b-a)$ 或 $\frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(\xi)}{g'(\xi)}$

2. **解出 $\theta$ 或 $\xi$ 的表达式**
   - 将 $\xi$ 用 $x$ 和已知量表示
   - 例如：由 $f(x) - f(x_0) = f'(x_0 + \theta(x-x_0))(x-x_0)$ 解出 $\theta$

3. **求极限**
   - 将 $\theta$ 表达式代入原式
   - 注意 $\theta$ 是 $x$ 的函数，不能当作常数

## 避坑指南

- **不能直接对原式取极限**，必须先解出 $\theta$ 表达式
- $\theta$ 是 $x$ 的函数，极限过程中会变化
- 注意 $\xi$ 所在的区间，$\theta\in(0,1)$ 是常见的约束条件
- 展开时 $\theta$ 通常以 $x_0 + \theta\Delta x$ 或 $\xi = x_0 + \theta(x-x_0)$ 形式出现
