# 辅助函数构造题

## 识别信号

- 证明题中出现 $f'(\xi)g(\xi)+h(\xi)f(\xi)=0$ 或 $f'(\xi)=\lambda f(\xi)$ 等形式
- 待证形式可以写成某个函数在两端点处函数值相等的结构
- 题目要求证明"存在 $\xi$ 使得..."的等式

## 常用构造模式表

| 待证形式 | 辅助函数 $F(x)$ |
|----------|-----------------|
| $f'(\xi)+\lambda f(\xi)=0$ | $F(x)=e^{\lambda x}f(x)$ |
| $f'(\xi)-\lambda f(\xi)=0$ | $F(x)=e^{-\lambda x}f(x)$ |
| $f'(\xi)g(\xi)-f(\xi)g'(\xi)=0$ | $F(x)=\dfrac{f(x)}{g(x)}$ |
| $f'(\xi)g(\xi)+f(\xi)g'(\xi)=0$ | $F(x)=f(x)g(x)$ |
| $f'(\xi)=\lambda f(\xi)$ | $F(x)=e^{-\lambda x}f(x)$ |
| $\xi f'(\xi)+f(\xi)=0$ | $F(x)=xf(x)$ |

## 步骤 SOP

1. **分析待证形式**
   - 将等式移项，识别导数项和原函数项的关系
   - 判断是哪种基本构造模式

2. **构造辅助函数**
   - 根据模式表选择对应的辅助函数 $F(x)$
   - 必要时做变量分离或恒等变形

3. **验证罗尔定理条件**
   - 验证 $F(x)$ 在 $[a,b]$ 连续
   - 验证 $F(a)=F(b)$
   - 则存在 $\xi\in(a,b)$ 使得 $F'(\xi)=0$

4. **反推原命题**
   - 计算 $F'(\xi)$ 并化简
   - 验证 $F'(\xi)=0$ 等价于原命题

## 避坑指南

- **先移项再反推**：不要凭感觉猜测辅助函数
- **验证 $F(a)=F(b)$**：这是使用罗尔定理的必要条件，构造后必须检查
- 复合形式可能需要多次尝试
- 有时需要先对原式做恒等变形再构造
