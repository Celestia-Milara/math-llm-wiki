### 任务 1：创建 04_Records 目录结构

**目的：** 补全核心闭环，让错题、重点题、概念审查有独立的记录单元

**操作：**
```bash
mkdir -p 04_Records/{Mistakes,KeyProblems,ConceptReviews,Reviews}
```

**迁移现有内容：**
- 将 `05_Outputs/MistakeAnalysis/` 中的错题分析拆分为单条记录
- 每条错题 → `04_Records/Mistakes/第6讲_题5_拉格朗日中值定理.md`
- 每条重点题 → `04_Records/KeyProblems/第6讲_题8_拉格朗日中值定理.md`
- 保留 `05_Outputs/MistakeAnalysis/` 作为汇总报告

**Frontmatter 模板（错题）：**
```yaml

标签: [数学, 错题记录, 第6讲]

### 任务 5：创建 Dataview 仪表盘

**目的：** 可视化学习状态

**创建 `05_Outputs/Dashboard.md`：**

```markdown
---
标题: 学习仪表盘
标签: [数学, 仪表盘]
创建日期: 2026-05-27
类型: 仪表盘
---

# 📊 学习仪表盘

## 待复习错题
```dataview
TABLE 讲次, 题号, 复习状态, 下次复习日期
FROM "04_Records/Mistakes"
WHERE 复习状态 = "待重做" OR 复习状态 = "已重做仍错"
SORT 下次复习日期 ASC
```

## 待复习重点题
```dataview
TABLE 讲次, 题号, 复习状态
FROM "04_Records/KeyProblems"
WHERE 复习状态 = "待复习"
SORT 创建日期 ASC
```

## Wiki 掌握状态
```dataview
TABLE 掌握状态, AI状态
FROM "03_Wiki"
SORT 创建日期 DESC
```

## 概念审查记录
```dataview
TABLE 概念, 理解状态, 是否需要更新Wiki
FROM "04_Records/ConceptReviews"
SORT 创建日期 DESC
```

## AI 状态统计
```dataview
LIST LENGTH(rows)
FROM "03_Wiki"
GROUP BY AI状态
```

## 各讲内容统计
```dataview
TABLE length(rows) AS "页面数"
FROM "03_Wiki"
GROUP BY 所有(file.tags)
```

   ```bash

   ```bash

   - 检查 Hubs 索引页中的链接是否有效

## 六、风险提示

1. **迁移过程中可能破坏双链** — 迁移后需要检查所有链接
2. **Frontmatter 统一可能影响 Dataview 查询** — 需要同步更新查询语句
3. **学习指南需要较多时间** — 可以分批创建，优先创建已学讲次的指南
