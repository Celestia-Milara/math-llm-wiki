# 行为准则

## 基本原则

- 原始资料优先：S0 不做静默正文改写。
- 少建页：不为填补链接或完善图谱创建低价值页面。
- 明确可信度：Wiki 用 `可信状态` 表示内容核查情况，不表示用户学习情况。
- 单一事实源：个人复习状态只在 `kaoyan`；本 Vault 仅提供资料定位。

## 链接与关系

- Wiki 链接使用真实的 Vault 内完整路径，例如 `[[03_Wiki/Concepts/导数-Derivative|导数]]`。
- 关系字段使用 Obsidian Link，而非路径字符串：`关联概念: [[03_Wiki/Concepts/导数-Derivative]]`。
- `来源` 是 S0/S1 的稳定路径；若来源不可验证，标记为待核查，不伪造链接。

## 可信状态

```text
S2 已核查 | S3 待核查 | S3 需修正
```

新建或 AI 整理的参考页默认 `S3 待核查`。只有人工确认内容后才可写为 `S2 已核查`。

## 历史内容

- 不删除旧学习记录、错题或输出报告。
- 可在历史目录增加说明、修复资料定位和标记无效关联。
- 不更新历史页中的 `复习状态`、`下次复习日期`，也不把它们解释为当前任务。

## 数学书写

- 行内公式用 `$...$`，独立公式用 `$$...$$`。
- 推导说明关键条件、定义域、端点、极限方向、参数范围和等价变形依据。
