# 行为准则

## 1. 基本原则

- 少建页，多更新已有页。
- 少写百科，多写“考研数学中怎么识别、怎么用、怎么避免错”。
- 错题分析优先分析用户的错误思路，而不是复述标准答案。
- AI 生成内容默认不等于已掌握，必须标注状态。

## 2. 链接规则

- 普通知识引用：`[[03_Wiki/Concepts/导数-Derivative|导数]]`
- 方法引用：`[[03_Wiki/Methods/辅助函数构造法-AuxiliaryFunction|辅助函数构造法]]`
- 题型引用：`[[03_Wiki/ProblemTypes/中值定理证明题|中值定理证明题]]`
- 记录页引用 Wiki 页时使用完整路径，便于 Dataview 查询。

## 3. 标签规范

基础标签：

```text
数学
```

章节标签：

```text
第1讲 第2讲 ... 第N讲
```

类型标签：

```text
概念 定理 方法 题型 专题索引
学习指南 日记 学习记录
错题记录 重点题记录 概念审查 复习记录
错题分析 弱点报告 复习计划 总结
```

不要混用 `06`、`第6讲`、`第六讲`。统一使用 `第6讲`。

## 4. 字段命名规范

统一使用中文字段：

```yaml
标题:
标签:
创建日期:
类型:
摘要:
来源:
AI状态:
```

Records 统一使用：

```yaml
讲次:
题号:
记录原因:
题目状态:
错因类型:
关联概念:
关联方法:
关联题型:
复习状态:
下次复习日期:
```

## 5. 状态值

`AI状态`：

```text
待核查 | 已核查 | 需修正
```

Concepts/Theorems 的 `掌握状态`：

```text
待编译 | 已建立心智模型 | 已练习验证
```

Methods/ProblemTypes 的 `问题类型`：

```text
null | 用不来 | 易混淆 | 易漏条件 | 计算易错 | 识别困难
```

Records 的 `复习状态`：

```text
待重做 | 已重做仍错 | 已纠正 | 待复习 | 已掌握
```

## 6. 数学书写规范

- 行内公式：`$...$`
- 独立公式：`$$...$$`
- 多行推导：

```latex
$$
\begin{aligned}
...
\end{aligned}
$$
```

- 复杂推导必须说明关键变形依据。
- 涉及极限、积分、换元、放缩时必须检查条件。

## 7. 禁止事项

- 不记录全部做题流水到 `04_Records/`。
- 不把学习指南写成教材摘要。
- 不把 DeepSeek 输出不加审查地写入 Wiki。
- 不覆盖已有 Wiki 正文。
- 不向旧目录写入新文件。
