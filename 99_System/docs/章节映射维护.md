# 章节映射维护

## 作用

`01_Raw/章节映射.json` 是 S1 定位数据，用于从科目、模块/章节、课程单元、资料类型和题号/行范围找到 S0 原始资料。

`mappings` 保留高等数学第 1—18 讲的兼容入口；`catalog` 收录线性代数、概率论和综合卷的题目、解析定位。没有讲义的科目必须明确为“未发现对应原始讲义”，不得虚构路径。

## 维护规则

- 原始讲义、题目或解析移动后，先更新映射和资料主索引，再验证。
- 高数的题目/解析行范围从 1 开始，结束行不得超过对应 Markdown 的实际行数。
- 非高数资料若尚无题号级边界，可记录整份文件的 `起始行: 1` 至实际末行；不要猜测题号范围。
- 新增资料必须填写 `科目`、`模块`、`课程单元`、资料类型与 Vault 内路径。
- 修改映射后更新 `last_updated`，并运行只读检查器。

## 验证

```powershell
python 99_System/scripts/check_vault.py
```

检查器会验证 JSON 解析、文件存在、起止行顺序和结束行边界；不会改写映射或原始资料。
