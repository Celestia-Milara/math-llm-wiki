# 章节映射维护

## 1. 作用

`01_Raw/章节映射.json` 是 AI 定位讲义、题干、解析的索引文件。

它服务于：

- 生成学习指南
- 分析错题
- 总结第 N 讲
- 从题号定位原题和解析

## 2. 使用规则

当用户提到“第 N 讲”“基础篇”“强化篇”“题号”时，优先读取章节映射。

不要靠文件名猜测题目范围。映射文件存在时，以映射为准。

## 3. 维护时机

需要更新映射的情况：

- 原始讲义或习题文件移动。
- 题目文件被拆分或合并。
- 行号范围变化。
- 新增讲次、习题册、解析册。

## 4. 字段建议

每个讲次建议包含：

```json
{
  "讲次": "第6讲",
  "标题": "",
  "讲义": "",
  "试题册": "",
  "解析册": "",
  "基础篇": {
    "试题起始行": 0,
    "试题结束行": 0,
    "解析起始行": 0,
    "解析结束行": 0
  },
  "强化篇": {
    "试题起始行": 0,
    "试题结束行": 0,
    "解析起始行": 0,
    "解析结束行": 0
  }
}
```

## 5. 校验规则

- JSON 必须能被解析。
- 文件路径必须存在。
- 结束行不得小于起始行。
- `last_updated` 修改后同步更新。
