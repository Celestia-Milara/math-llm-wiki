# 数学资料库结构

## 1. 定位

本 Vault 保存并定位数学原始资料与通用参考知识。个人复习状态只保存在只读协作 Vault `kaoyan`，本仓库不建立镜像。

## 2. 顶层目录

```text
00_Inbox/       待整理资料输入
01_Raw/         S0 原始资料与 S1 索引：讲义、题目、解析、图片、章节映射
02_Learning/    L 历史学习产物；不再新增活动内容
03_Wiki/        S2/S3 通用数学参考：概念、定理、方法、题型、索引
04_Records/     L 历史个人记录；不再新增错题或复习状态
05_Outputs/     L 历史分析与仪表盘；不作为当前复习入口
06_Templates/   资料索引与 Wiki 维护模板；旧学习模板不再使用
99_System/      规则、schema、提示词与只读校验脚本
```

## 3. 资料导航模型

资料按以下模型描述：

```text
科目 → 模块/章节 → 课程单元 → 资料类型 → 题号或行范围
```

- 高等数学保留兼容的“第 N 讲”入口，并在 `章节映射.json` 保存讲义、题目和解析的行范围。
- 线性代数、概率论和综合卷使用分科索引定位到实际题目/解析文件；没有原始讲义时必须明确说明。
- `01_Raw/资料主索引.md` 是人工导航入口；索引只链接真实文件。

## 4. 历史区边界

`02_Learning/`、`04_Records/`、`05_Outputs/` 中的日期、错题和复习状态是历史快照，不是当前任务。可保留来源和日期以便追溯，但不得据此生成计划或更新状态。

## 5. 禁止写入

不得向本 Vault 写入当前日记、进度、掌握证据、待办、复习计划或个人错题状态；也不得向旧路径 `00_Raw/`、`01_Wiki/`、`02_Output/`、`03_Daily/`、`04_Templates/` 写入。
