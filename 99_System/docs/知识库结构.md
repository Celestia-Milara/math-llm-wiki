# 知识库结构

## 1. 设计原则

目录按“资料来源 -> 学习过程 -> 永久知识 -> 个人记录 -> 汇总输出 -> 系统规则”分层。

判断文件归属时只问一个问题：这个文件主要服务什么？

- 原始资料：放 `01_Raw/`
- 当天学习过程：放 `02_Learning/`
- 可长期复用的知识：放 `03_Wiki/`
- 个人错题/重点题/理解审查：放 `04_Records/`
- AI 汇总报告：放 `05_Outputs/`
- 模板：放 `06_Templates/`
- 系统规则、脚本、提示词：放 `99_System/`

## 2. 顶层目录

```text
00_Inbox/
  临时输入、截图、还没整理的问题。

01_Raw/
  Lectures/      教材、讲义 Markdown。
  Problems/      习题题干与解析。
  images/        原始图片。
  Archive/       已处理素材归档。
  章节映射.json  讲次与题目定位索引。

02_Learning/
  Guides/        某讲学习指南。
  Daily/         每日学习日志。
  Sessions/      单次学习记录。

03_Wiki/
  Concepts/      概念、定义、性质。
  Theorems/      定理、公式、推论。
  Methods/       解题方法、SOP、技巧。
  ProblemTypes/  题型、识别信号、训练策略。
  Hubs/          章节或专题索引。

04_Records/
  Mistakes/       错题记录。
  KeyProblems/    重点题记录。
  ConceptReviews/ 概念理解审查。
  Reviews/        重做、复盘、阶段复习记录。

05_Outputs/
  MistakeAnalysis/  错题分析报告。
  WeaknessReports/  弱点报告。
  ReviewPlans/      复习清单与计划。
  StageSummaries/   讲次总结、阶段总结。

06_Templates/
  所有 Obsidian 模板。

99_System/
  docs/       规则文档。
  schemas/    字段规范。
  prompts/    DeepSeek API 调用提示词。
  scripts/    自动化脚本。
```

## 3. 归档边界

### `02_Learning` 与 `05_Outputs`

- 学习指南、日记、单次学习记录属于 `02_Learning`。
- 错题分析、弱点报告、复习计划、阶段总结属于 `05_Outputs`。

### `03_Wiki` 与 `04_Records`

- “导数是什么”“中值定理怎么用”属于 `03_Wiki`。
- “我在第 6 讲第 8 题把绝对值当作可导函数展开”属于 `04_Records`。

### `04_Records/Mistakes` 与 `04_Records/KeyProblems`

- 做错且需要追踪：`Mistakes`
- 没做错但值得反复训练、题型典型、方法关键：`KeyProblems`

## 4. 禁止写入旧目录

以下旧目录不再使用：

```text
00_Raw/
01_Wiki/
02_Output/
03_Daily/
04_Templates/
docs/
scripts/
```

如果旧路径出现在历史文件中，应逐步改为新路径。
