# 资料库维护

## 维护边界

本仓库维护 S0 原始资料、S1 定位数据以及 S2/S3 Wiki 参考内容。不得在此维护个人进度、错题任务、日记或复习计划；这些信息只在 `kaoyan` 中维护，本项目对其只读。

## 查找资料

1. 打开 `01_Raw/资料主索引.md`，按科目进入。
2. 高等数学按“第 N 讲”再读 `01_Raw/章节映射.json`，用对应题目/解析行范围定位。
3. 引用资料时记录科目、章节/讲次、题号（如有）和 Vault 内路径。

## 可信状态

- `S0 原始资料`：讲义、题目、解析和图片，保持原貌。
- `S1 定位数据`：索引和映射，只用于定位。
- `S2 已核查`：人工确认的参考页。
- `S3 待核查` / `S3 需修正`：AI 或尚未人工确认的参考页。
- `L 历史学习数据`：旧学习记录或报告，不能作为当前状态。

## 两库导航

可复制 `math` 的 Vault 内路径到 `kaoyan`，或使用：

```text
obsidian://open?vault=math&file=01_Raw/资料主索引
```

URI 的 `file` 值不含 `.md`，使用 `/`；包含空格或特殊字符时需 URL 编码。两个 Vault 不使用跨 Vault Dataview、任务查询或自动双向同步。

## 只读检查

```powershell
python 99_System/scripts/check_vault.py
```

检查器验证内部链接、核心 schema、章节映射路径和行范围、Wiki 可信状态、旧活动字段和关系链接。默认只读；没有自动修复模式。
