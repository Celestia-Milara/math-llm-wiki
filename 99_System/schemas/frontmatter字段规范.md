# Frontmatter 字段规范

## 1. 通用字段

所有长期文件建议包含：

```yaml
标题:
标签: [数学]
创建日期: YYYY-MM-DD
类型:
摘要:
来源:
AI状态: 待核查
```

`AI状态` 可选值：

```text
待核查 | 已核查 | 需修正
```

非 AI 生成内容可以省略 `AI状态`。

## 2. Wiki 页面

### Concepts / Theorems

```yaml
标题:
标签: [数学, 第N讲, 概念]
创建日期:
类型: 永久笔记
掌握状态: 待编译
摘要:
来源:
AI状态: 待核查
```

`掌握状态`：

```text
待编译 | 已建立心智模型 | 已练习验证
```

### Methods / ProblemTypes

```yaml
标题:
标签: [数学, 第N讲, 方法]
创建日期:
类型: 永久笔记
问题类型:
问题备注:
最后练习:
摘要:
来源:
AI状态: 待核查
```

`问题类型`：

```text
null | 用不来 | 易混淆 | 易漏条件 | 计算易错 | 识别困难
```

```yaml
创建日期:
类型: 题目记录
讲次:
题号:
来源:
记录原因: 错题
题目状态: 首次做错

关联概念: []
关联方法: []
关联题型: []
复习状态: 待重做
```


## 4. 概念审查

```yaml
标题:
标签: [数学, 概念审查]
创建日期:
类型: 概念审查
概念:
关联Wiki:
理解状态:
是否需要更新Wiki:
```

`理解状态`：

```text
基本正确 | 有偏差 | 已修正 | 仍需练习
```
