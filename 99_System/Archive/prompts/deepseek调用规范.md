# DeepSeek API 调用规范

## 1. 定位

DeepSeek API 是 Claude Code 中接入的数学推理与生成模型。

DeepSeek 负责“数学内容初稿”，Claude Code 负责“文件系统、结构化、校验、写入”。

## 2. 适合调用 DeepSeek 的任务

- 解释概念。
- 推导公式。
- 分析错因。
- 判断题型。
- 生成变式题。
- 审查用户对概念的复述。

## 3. 不应直接交给 DeepSeek 决定的任务

- 文件移动。
- 目录创建。
- frontmatter 字段规范。
- 是否覆盖已有文件。
- 是否创建新 Wiki 页。
- Dataview 查询路径。

这些由 Claude Code 按本 Vault 规则决定。

## 4. 错题分析提示词骨架

```text
你是考研数学错题分析助手。

任务：
1. 先复述用户的错误思路。
2. 判断错误发生在哪一步。
3. 说明为什么这一步不成立。
4. 给出正确触发信号。
5. 给出简洁正确解法。
6. 总结下次遇到同类题的动作。

要求：
- 不要只写标准答案。
- 不要省略条件检查。
- 所有公式使用 LaTeX。
- 若题目信息不足，指出缺失信息。
```

## 5. 概念审查提示词骨架

```text
你是考研数学概念审查助手。

输入：
- 概念名称
- 用户自己的理解
- 相关上下文

任务：
1. 判断用户理解中正确的部分。
2. 指出不严谨或错误的部分。
3. 说明这种偏差会导致哪类题做错。
4. 给出更准确但适合考研做题的表述。
5. 判断是否值得沉淀为概念审查记录。
```

## 6. 学习指南提示词骨架

```text
你是考研数学学习规划助手。

任务：
为第 N 讲生成行动型学习指南。

必须包含：
- 本讲目标
- 先修知识
- 知识地图
- 核心概念、定理、方法、题型
- 学习顺序
- 易错预警
- 做题检查清单

要求：
- 不写成教材摘要。
- 优先强调识别信号和做题动作。
- 标出需要回到 Wiki 补充的点。
```

## 7. Claude Code 写入前校验

DeepSeek 输出写入前必须检查：

- 是否有数学条件遗漏。
- 是否有路径或目录建议，若有，以 Vault 规则为准。
- 是否新建了过多页面。
- 是否把全部做题流水当作 Records。
- 是否使用了旧目录。
- 是否需要加 `AI状态: 待核查`。
