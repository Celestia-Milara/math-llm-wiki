# 快捷指令

## 1. 生成学习指南

触发：

```text
学习第N讲
生成第N讲学习指南
```

读取：

- `01_Raw/章节映射.json`
- `01_Raw/Lectures/`
- `01_Raw/Problems/`
- `03_Wiki/` 中标签含 `第N讲` 的页面

输出：

```text
02_Learning/Guides/YYYY-MM-DD_第N讲学习指南.md
```

内容：

- 本讲目标
- 先修知识
- 知识地图
- 核心概念、定理、方法、题型
- 学习顺序
- 易错预警
- 做题检查清单

## 2. 分析今日错题

触发：

```text
分析今天错题
分析 YYYY-MM-DD 错题
```

读取：

- `02_Learning/Daily/YYYY-MM-DD.md`
- `01_Raw/章节映射.json`
- 对应题干和解析
- 已有 `03_Wiki/` 页面

输出：

```text
05_Outputs/MistakeAnalysis/YYYY-MM-DD_错题分析.md
```

必要时创建或更新：

```text
04_Records/Mistakes/
04_Records/KeyProblems/
```

要求：

- 必须引用用户错误思路原文。
- 必须指出错误发生在哪一步。
- 必须给出下次识别信号。
- 不记录全部做过的题。

## 3. 审查我的理解

触发：

```text
审查我对 XXX 的理解
```

流程：

1. 解释概念。
2. 等用户复述。
3. 审查正确点、偏差点、做题风险。
4. 给出修正版理解。
5. 仅在有长期价值时写入：

```text
04_Records/ConceptReviews/YYYY-MM-DD_概念名_理解审查.md
```

## 4. 总结第N讲

触发：

```text
总结第N讲
```

输出：

```text
05_Outputs/StageSummaries/YYYY-MM-DD_第N讲总结.md
```

聚合：

- `03_Wiki/` 的知识页面
- `04_Records/` 的错题和重点题
- `05_Outputs/MistakeAnalysis/` 的历史错题分析

## 5. 弱点跨分析

触发：

```text
弱点跨分析
生成弱点报告
```

输出：

```text
05_Outputs/WeaknessReports/弱点报告.md
```

聚合：

- 高频错因
- 薄弱方法
- 薄弱题型
- 重复犯错题目
- 下阶段复习建议
