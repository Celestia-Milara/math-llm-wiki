# 总结第N讲

## 1. 目标

讲次总结不是学习指南，也不是错题分析。

它回答：

```text
这一讲现在掌握得怎么样？
哪些知识和题型已经形成体系？
哪些错因反复出现？
下一轮复习应该做什么？
```

## 2. 输入

必须读取：

- `01_Raw/章节映射.json`
- `03_Wiki/` 中标签含 `第N讲` 的页面
- `04_Records/Mistakes/`
- `04_Records/KeyProblems/`
- `04_Records/ConceptReviews/`
- `05_Outputs/MistakeAnalysis/`

## 3. 输出位置

```text
05_Outputs/StageSummaries/YYYY-MM-DD_第N讲总结.md
```

## 4. 输出结构

```text
# 第N讲总结

## 本讲知识地图

## 核心概念与定理

## 核心方法与题型

## 历史错题与错因

## 概念理解偏差

## 未核查或待补页面

## 下轮复习任务
```

## 5. 判断标准

可以标记为薄弱点的情况：

- 同一方法重复出错。
- 同一题型识别失败。
- 概念审查中出现关键偏差。
- Records 中复习状态仍为 `待重做` 或 `已重做仍错`。

## 6. 特殊处理

- 没有 Records：说明“暂无个人错题记录”，不要凭空推断。
- Wiki 页面为空：标记 `[待编译]`。
- AI 页面未核查：标记 `[AI待核查]`。
- 跨讲次知识：标记 `[跨讲次: 第M讲]`。
