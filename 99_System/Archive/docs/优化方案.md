## 三、具体任务

### 任务 1：填充 04_Records 错题记录

**目的：** 补全核心闭环，让错题有独立的记录单元，支持复习调度

**迁移策略：每道错题一个文件**

文件命名：`{讲次简称}_题{题号}_{知识点关键词}.md`

示例：
- `06_题5_拉格朗日中值定理极限.md`
- `06_题8_拉格朗日中值定理放缩.md`
- `05_题2_极值点含参逆向.md`

**保留原文件：** `05_Outputs/MistakeAnalysis/` 保留作为汇总索引，不删除

**Frontmatter 模板（错题）：**
```yaml
标题: 06_题5 拉格朗日中值定理极限
标签: [数学, 错题记录, 第6讲, 拉格朗日中值定理]
创建日期: 2026-05-11
类型: 错题记录
讲次: 第6讲
题号: 5
来源: 05_Outputs/MistakeAnalysis/2026-05-11_第6讲错题分析.md
记录原因: 错题
题目状态: 首次做错
错因类型: 方法选择
错因详情: 带参数θ的极限问题，应先解出θ再求极限，而非直接对原式取极限
正确触发信号: 看到"存在θ∈(0,1)"形式 → 先解出θ表达式
关联概念: ["03_Wiki/Concepts/拉格朗日中值定理"]
关联方法: []
关联题型: ["03_Wiki/ProblemTypes/中值定理极限题"]
复习状态: 待重做
下次复习日期: 2026-06-03
AI状态: 待核查
```

**关键改进：**
- `来源` 指向原始分析文件（保留溯源路径）
- 新增 `错因详情` 和 `正确触发信号`（支持复习时回忆）
- `下次复习日期` 使用间隔重复算法（首次错→1天，重做仍错→3天，掌握→7天）

### 任务 4：统一 Frontmatter 字段

**目的：** 解决中英文混用问题，确保 Dataview 查询正常工作

**规范（按行为准则）：**

| 字段 | 用途 | 示例值 |
|------|------|--------|
| `标题` | 页面标题 | `06_题5 拉格朗日中值定理极限` |
| `标签` | 分类标签 | `[数学, 错题记录, 第6讲]` |
| `创建日期` | 创建时间 | `2026-05-11` |
| `类型` | 页面类型 | `错题记录` / `学习指南` / `专题索引` |
| `来源` | 数据来源 | `05_Outputs/MistakeAnalysis/...` |
| `AI状态` | 核查状态 | `待核查` / `已核查` |

**Records 额外字段：**
- `讲次`、`题号`、`记录原因`、`题目状态`
- `错因类型`、`错因详情`、`正确触发信号`
- `关联概念`、`关联方法`、`关联题型`
- `复习状态`、`下次复习日期`

**检查方法：**
```bash
# 查找使用英文字段的文件（应返回 0）
grep -r "^tags:" 03_Wiki/ 04_Records/ 05_Outputs/ 2>/dev/null | wc -l
grep -r "^date:" 03_Wiki/ 04_Records/ 05_Outputs/ 2>/dev/null | wc -l
grep -r "^type:" 03_Wiki/ 04_Records/ 05_Outputs/ 2>/dev/null | wc -l
```

**修复方法：**
手动逐文件修复（数量不多），不使用批量脚本（避免误改）。
