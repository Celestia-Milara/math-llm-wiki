## 一、拉格朗日中值定理

### 题5 — 拉格朗日中值定理与极限计算

**题干**：设存在 $0 < \theta < 1$，使得 $\arcsin x = \frac{x}{\sqrt{1 - (\theta x)^2}}$，$-1 \leqslant x \leqslant 1$，则 $\lim_{x \to 0} \theta =$ ?

**关键思路**：
1. 将 $\theta$ 用 $x$ 表达：$\theta^2 = \frac{1 - \frac{x^2}{\arcsin^2 x}}{x^2} = \frac{\arcsin^2 x - x^2}{\arcsin^2 x \cdot x^2}$
2. 利用 $\arcsin x = x + \frac{1}{6}x^3 + o(x^3)$ 展开，得 $\arcsin^2 x - x^2 \sim \frac{1}{3}x^4$
3. 代入极限得 $\lim_{x \to 0} \theta = \frac{\sqrt{3}}{3}$

**易错点**：需要将 $\theta$ 解出来后再求极限，而不是对原式直接取极限。

### 题8 — 拉格朗日中值定理放缩（**重点分析**）

**题干**：设 $f(x)$ 可导，$|f'(x)| \leqslant 1$，$f(0) = 1$，证明 $|f(x)| \leqslant 1 + x$，$0 < x < 1$。

**正确思路**：
由拉格朗日中值定理：$f(x) - f(0) = f'(\xi)x$，$\xi \in (0, x)$
则 $|f(x)| = |f(0) + f'(\xi)x| \leqslant 1 + |f'(\xi)|x \leqslant 1 + x$

**你的错误**：
1. 错误地对 $|f(x)|$ 直接使用泰勒展开：$|f(x)| = |f(0)| + |f'(x)|x + o(x^2)$
   - **问题**：绝对值不可导，不能直接对 $|f(x)|$ 展开
   - **正确做法**：先对 $f(x)$ 使用中值定理，再取绝对值放缩
2. 对拉格朗日中值定理的运用不够熟练
   - **关键**：$|f'(x)| \leqslant 1$ 的条件提示用拉格朗日中值定理控制 $f(x)$ 的变化幅度

## 二、泰勒公式

### 题12 — 泰勒展开与不等式证明

**题干**：(1) 将 $\sin x$ 在 $x=0$ 处展开成一阶带拉格朗日余项的泰勒公式；
(2) 证明 $\left|\frac{\sin x}{x} - 1\right| \leqslant \frac{1}{2}|x|$，$x \neq 0$。

**关键思路**：
1. $\sin x = x - \frac{\sin \xi}{2}x^2$（$\xi$ 介于 0 与 $x$ 之间）
2. 代入得 $\left|\frac{\sin x}{x} - 1\right| = \left|\frac{\sin \xi}{2}x\right| \leqslant \frac{1}{2}|x|$

**易错点**：
- 一阶带拉格朗日余项的展开是 $\sin x = \sin 0 + \sin'(0)x + \frac{\sin''(\xi)}{2!}x^2$
- 注意二阶导 $\sin''(\xi) = -\sin\xi$，所以余项是 $-\frac{\sin\xi}{2}x^2$

## 三、函数零点与交点

### 题13 — 利用导数研究函数形态求交点个数

**题干**：求曲线 $y = \mathrm{e}^{-x/2}$ 与 $y = x^3 - 3x$ 的交点个数。

**关键思路**：
1. 令 $f(x) = \mathrm{e}^{-x/2} - x^3 + 3x$
2. 分析导数符号判断单调区间：$f'(x) = -\frac12\mathrm{e}^{-x/2} - 3x^2 + 3$
3. 通过 $f'''(x) < 0$ 推出 $f''(x)=0$ 至多一根 $\Rightarrow$ $f'(x)=0$ 至多两根 $\Rightarrow$ $f(x)=0$ 至多三根
4. 计算关键点函数值：$f(-\sqrt3) > 0$，$f(-1) < 0$，$f(1) > 0$，$f(2) < 0$
5. 由零点定理，三个区间各有一根，共 3 个交点

**方法总结**：求交点个数 $\rightarrow$ 构造函数 $f(x) = g(x) - h(x)$ $\rightarrow$ 逐阶求导分析单调区间 $\rightarrow$ 零点定理判定

## 四、不等式证明

### 题18 — 利用极值证明双边不等式

**题干**：$0 \leqslant x \leqslant 1$，$p > 1$，证明 $\frac{1}{2^{p-1}} \leqslant x^p + (1-x)^p \leqslant 1$。

**关键思路**：
1. 令 $f(x) = x^p + (1-x)^p$
2. $f'(x) = p[x^{p-1} - (1-x)^{p-1}]$，令 $f'(x)=0$ 得 $x = \frac12$
3. $f''(\frac12) = 2p(p-1)(\frac12)^{p-2} > 0$，故 $\frac12$ 为极小值点
4. 最小值 $f(\frac12) = \frac{1}{2^{p-1}}$，最大值 $f(0) = f(1) = 1$

**方法总结**：对称区间上的函数，极值点往往在对称中心处。

## 五、罗尔定理与辅助函数构造

### 题20 — 辅助函数构造（**重点分析**）

**题干**：$f(x)$ 在 $[a,b]$ 连续，$(a,b)$ 可导 $(a>0)$，证明 $(a,b)$ 内 $2x[f(b)-f(a)] = (b^2-a^2)f'(x)$ 至少有一个实根。

**关键思路**：
1. 结论变形为 $(b^2-a^2)f'(x) - 2x[f(b)-f(a)] = 0$
2. 构造辅助函数的**核心方法**：将 $f'(x)$ 视为某函数的导数，反推原函数
   - $(b^2-a^2)f'(x)$ 的原函数是 $(b^2-a^2)f(x)$
   - $-2x[f(b)-f(a)]$ 的原函数是 $-[f(b)-f(a)]x^2$
3. 故令 $F(x) = (b^2-a^2)f(x) - [f(b)-f(a)]x^2$
4. 验证 $F(a) = F(b) = b^2f(a) - a^2f(b)$，由罗尔定理得证

**辅助函数构造方法总结**：
| 步骤 | 操作 |
|------|------|
| ① 移项 | 将要证明的等式化为 $g(x)f'(x) + h(x)[f(b)-f(a)] = 0$ 形式 |
| ② 观察 | 识别 $f'(x)$ 系数与 $f(b)-f(a)$ 系数的关系 |
| ③ 反推 | 将 $f'(x)$ 视作 $F'(x)$ 的一部分，反推 $F(x)$ |
| ④ 验证 | 验证 $F(a) = F(b)$，用罗尔定理 |

### 题22 — 罗尔定理与导数的介值定理

**题干**：$f(x)$ 在 $[a,b]$ 可导，$c \in (a,b)$，证明：
(1) 存在 $\xi \in (a,c)$，$f(c)-f(a) = f'(\xi)(c-a)$
(2) 存在 $\eta \in (a,b)$，$f(b)-f(a) = f'(\eta)(b-a)$ 且 $\eta > \xi$

**关键思路**：
1. **(1)** 构造 $G(x) = f(x) - \frac{f(c)-f(a)}{c-a}(x-a)$，$G(a)=G(c)=f(a)$，罗尔定理即得
2. **(2)** 利用加权平均思想：
   $$
   \frac{f(b)-f(a)}{b-a} = t f'(\gamma) + (1-t)f'(\xi)
   $$
   其中 $\gamma \in (c,b)$，$t = \frac{b-c}{b-a} \in (0,1)$
   该值介于 $f'(\gamma)$ 与 $f'(\xi)$ 之间，由导数的介值定理，存在 $\eta$ 等于该值。

**易错点**：第(2)问需要结合第(1)问的结论，利用加权平均 + 导数的介值定理。
